# Ray Nx SaaS migration implementation audit

Audit snapshot: 2026-08-09. This document separates repository implementation
from production evidence. A checked-in script or a passing local test is never
recorded as proof that a production gate has elapsed or succeeded.

## Status model

- `IMPLEMENTED`: repository code, configuration and local verification exist.
- `EXTERNAL GATE`: requires CI history, provider credentials, production data,
  elapsed observation time or an actual deployment.
- `FUTURE CONTRACT`: intentionally forbidden until the rollback window closes.

## Nx 24 compatibility boundary

The verified workspace baseline is Nx 23.0.1, Node 24.14.1 and pnpm 10.25.0.
This pass removes APIs that Nx states will disappear in Nx 24 without mixing a
framework-major upgrade into the boundary migration:

- Application Vite builds use Vite 8's native `resolve.tsconfigPaths`.
- Nx/Vitest library and service configs use exact `vite-tsconfig-paths` 6.1.1
  with explicit root/project configs. Native resolution was tested and rejected
  for these configs because it lost root aliases and Engine's `#/*` alias.
- No project had a real Vite build target that needed the Markdown copies
  previously declared through `nxCopyAssetsPlugin`; the obsolete copy operation
  was removed rather than replaced with a new side-effect plugin.

The Nx 24 upgrade remains a separate merge wave. The closed and open peer gates,
including TanStack/Rspack, Tailwind/Vite 8, Expo/Detox/Zeego and Electron Forge,
are recorded in `docs/migrations/nx24-peer-matrix.md`. After those decisions,
run `nx migrate` and the full no-cache validation matrix. The recurring
`nx configure-ai-agents` notice is tooling metadata debt, not a runtime or CI
correctness failure, and must be reviewed as its own generated-config diff.

## Completion boundary

The repository portion is not equivalent to production completion. The goal
must remain open while any `EXTERNAL GATE` is outstanding. In particular, do
not run Contract, remove rollback images or claim the CI/RTO targets until the
ledger contains the corresponding real evidence.
